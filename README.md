# Vespa Text Search Application

Локальное приложение для полнотекстового поиска с поддержкой ключевого, семантического и гибридного поиска на основе Vespa.

## Предварительные требования

### Системные требования
- **Docker** (рекомендуется использовать Docker Desktop для удобства работы с логами)
- Python 3.7+

### Установка зависимостей
```bash
pip install -r requirements.txt
```

## Подготовка данных

### Вариант 1: Скачать готовые файлы
1. Скачайте архив с данными по ссылкам:
   - [news.jsonl](https://disk.yandex.ru/d/IJ7wRZQ9aRlS-g)
   - [news_indexed.jsonl](https://disk.yandex.ru.ru/d/npzMJtLseFPitQ)
2. Распакуйте и замените соответствующие файлы в проекте

### Вариант 2: Сгенерировать файлы самостоятельно
1. Скачайте только `news.jsonl`
2. Запустите скрипт преобразования:
```bash
python scripts/jsonl_to_indexed_jsonl.py
```
Это создаст файл `news_indexed.jsonl` в формате, пригодном для индексирования в Vespa.

## Запуск приложения

Для развертывания приложения выполните:

```bash
python scripts/app.py
```

Приложение будет развернуто локально с использованием Docker контейнеров Vespa.

## Тестирование поиска

Для проверки работы текстового поиска запустите:

```bash
python scripts/semantic_search.py
```

Этот скрипт демонстрирует работу трех типов поиска:
- **Ключевой поиск** - традиционный полнотекстовый поиск
- **Семантический поиск** - поиск по смыслу с использованием векторных представлений
- **Гибридный поиск** - комбинация ключевого и семантического поиска

## Структура проекта

- `scripts/app.py` - основной скрипт для развертывания приложения
- `scripts/semantic_search.py` - тесты поисковых возможностей
- `scripts/jsonl_to_indexed_jsonl.py` - утилита для преобразования данных
- `news.jsonl` - исходные данные статей
- `news_indexed.jsonl` - проиндексированные данные для Vespa
- `requirements.txt` - зависимости Python

## Примечания

- Убедитесь, что Docker запущен перед развертыванием приложения
- Для мониторинга работы приложения используйте Docker Desktop
- Файлы данных должны быть в кодировке UTF-8
